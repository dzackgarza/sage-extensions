`general_image_certificate` (the general certificate) and `divisor_two_regression`

## The general certificate

Let `G = O(L)`, `H = Stab_G(x)` for a primitive isotropic line `x`, `N = ker rho`,
`c = [v/div v]` for a generator `v` of `x`. `N` is normal in `G`, so the `N`-orbits
inside the single `G`-orbit `Gx` are the double cosets `N \ G / H`, and the
orbit--stabilizer theorem for the action of `G/N = im rho` identifies those with
`im rho / rho(H)`. The datum map `N g x |-> rho(g) D`, with `D = {c, -c}`, has fibre over `D` of size

    [Stab_{im rho}(D) : rho(H)].

Proof of the fibre statement: if `rho(g') = rho(g) rho(h)` with `h` in `H` then
`g' = n g h` for `n = g'(gh)^{-1}`, which lies in `ker rho = N` because
`rho(g'(gh)^{-1}) = rho(g')rho(h)^{-1}rho(g)^{-1} = 1`; so `g'` and `gh` are in the
same `N`-orbit. Nothing about a plane's complement enters.

The datum for an *unoriented* line is the set `{c, -c}` (one element when `c = -c`),
because `H` may interchange `v` and `-v`; a signed primitive vector fixed in
orientation uses `c` and the vector stabilizer. Both groups in the index must be changed.

`general_image_certificate(quotient, representative)` returns `1` if the
image of the exhibited ambient line-stabilizer family has the order of the
setwise stabilizer of `D(x)` inside the actual ambient `im rho` (not the
selected subgroup's image or all of `O(A_L)`). Containment follows from
equivariance, so equality of orders proves equality of groups. If the
exhibited image is smaller, `None` means that the shortcut does not certify
the index, not that the exact index is necessarily greater than one. The caller
uses the integral double-coset route instead. For a sign-only quotient, the
analogous sufficient certificate compares the exhibited stabilizer's sign
image with the ambient sign image.

## Why the old shortcut was not a proof

`_complement_discriminant_surjective` (deleted) argued: `1_plane + gamma` lies in
`Stab(v)`, its image is the complement's discriminant action, and at a divisor-1
line the complement's discriminant group is the ambient one. The last clause is
false for a divisor-2 line of a glued overlattice, and the extension claim is false
independently: on `L = M + Z w` with `M = U(2) perp <2>^5`, `w = (e+k1+k2+k3+k4)/2`,
`L` is even integral of signature (6,1), `det L = -32`, `e` is primitive of divisor
two, and the complement of `<e,f>` is `K = <2>^5`. The signed permutations realize
the whole `O(q_K)`, and the swap `k4 <-> k5` extended by the identity on `<e,f>` is
an isometry of `L (x) QQ` (`S^t G S = G`, checked entrywise) that fixes `e` and `f`
and is **not integral** in `L`'s basis: it sends `w` to `w + (k5-k4)/2`, whose
`k4`-coordinate is `-1/2`. Complement surjectivity therefore does not give the
integral extension; the gluing subgroup has to be preserved, and the fibre index
above is what decides the orbit count.

`divisor_two_regression` test
`test_the_complement_swap_does_not_extend_across_the_gluing` states exactly this,
with the rational coordinate vector and the form preservation computed.

## The independent positive divisor-two case

`B = U perp <-1>^2`, `T = B(2)`, basis `(e,f,d1,d2)`, `v = e`, `div_T(e) = 2`.
An integral isometry of `T` reduces mod 2 to a binary matrix preserving
`x^t G_B x mod 4` on all sixteen vectors, and fixing `[e/2]` forces the first column
to be `e`. Enumerating all `15^3` such columns leaves exactly four matrices, with
column bitmasks

    (1,2,4,8), (1,2,8,4), (1,15,5,9), (1,15,9,5),

which is precisely the group generated by the reductions of the two integral
elements the stabilizer presents: the swap `d1 <-> d2`, and the transvection
`E(e, d1+d2)(x) = x - b(d1+d2,x)e + b(e,x)(d1+d2) + b(e,x)e`, whose parameter has
even norm `b(d1+d2,d1+d2) = -2`. `test_the_positive_divisor_two_image_is_the_four_enumerated_matrices`
enumerates the four, exhibits the two, and checks that the two generate all four.
The whole computation is integer arithmetic and does not consult the
implementation under test.

## Second round: the lower bound is the ambient owner's, and the datum is the set

The first delivery computed the target in the ambient image but the lower bound
from `quotient.subgroup.isotropic_stabilizer_generators`, the *selected*
subgroup's stabilizer family.  For `Gamma = ker rho` every element of that
family has trivial image, so the lower bound was trivial while the independent
ambient stabilizer image need not be, and the certificate then reported an
index for a group the caller never walks.  The lower bound is now
`quotient.supergroup.isotropic_stabilizer_generators(representative)` — the
ambient `O(L)` line stabilizer's own exhibited family, whose image is
`rho(Stab_{O(L)}(x))` and lies in the datum's stabilizer by construction.

A sign-only quotient retains no discriminant factor: the datum is trivial in
every component it has, its stabilizer inside the retained image is the whole
image, and the certificate now answers that case from the sign patterns of the
ambient generators and of the ambient stabilizer family (F2-spans of the sign
components) instead of reading `_discriminant_group`, which such a quotient does
not have.

`_line_orbit_from_divided_classes` treated the *signed* class `c` as the datum
and divided orders by floor division.  The line's datum is the set `{c, -c}` —
its stabilizer may carry `v` to `-v` — so the setwise index is now computed
from the signed class orbit the walk already performs (the set orbit has half the signed orbit size if `c != -c` and the walk meets `-c`, and the same size otherwise; the setwise
stabilizer order is twice the signed one exactly in the first case),
with `rho(H)` from `stabilizer_discriminant_image`, the ambient setwise owner.
Its representatives are now admitted only when the ambient group exhibits an
isometry from the chosen representative onto each constructed line.

## Third round (superseded attempt): the certificate returns the walk, and the consumer transports

`general_image_certificate` certified the fibre index but returned `1`, and
`_line_orbit_from_divided_classes` then rebuilt the orbit's lines by searching
`isotropic_lines_by_divided_class` and admitting them with
`isotropic_equivalence_witness` — a divided-class search and a general isometry
search per line, neither of which is a transporter.

The certificate now returns the walk itself.  After the two orders agree it
chooses an exactly generating subfamily of the ambient discriminant images by
membership in the subgroup accumulated so far (`libgap.IN`), keeping beside each
kept image the integral generator that produces it
(`ambient_discriminant_images()` and `_ambient_generators()` index the same
family, so no `rho` is evaluated again and no section is rebuilt per edge), and
walks the datum orbit breadth-first over that subfamily.  A finite image
generates as a monoid, so the walk is exhaustive; every new datum is reached by
the one-step image of its predecessor and is stored with its actual integral
transporter, `isometry ∘ transporter` — the ambient generator composed after the
path.  The first pair is the representative with the identity.  `None` remains
the undecided answer, unchanged.

`_line_orbit_from_divided_classes` now reads that walk and returns the actual
images `transporter(representative)`; it no longer searches for vectors or for
isometries, and it refuses (`ArithmeticError`) if a transporter's image of the
representative has a divided class outside the datum it was walked to.  Its
index bookkeeping is gone with it: the certificate is that computation, once.

The sign-only branch returns the single-point orbit `(datum, identity)`, so the
return type is uniform; the stable-only path still needs no sign witness, and the
joint-character saturation checks in `isotropic_line_stabilizer_image` are
untouched.

the claimed transports. The return-type change also broke the existing

## Ambient line classification on scaled odd-rank unimodular forms

The full consumer's older timeout traceback was in the ambient marking
classification (`primitive_vector_classes` -> pointed isometry -> integral
lift torsor), before the finite fibre walk, not evidence of a false fibre
certificate. The newer pinned run was interrupted without a verdict. A
separate pinned test of just the ambient Coble line row entered the test
call and was terminated by its 90-second outer deadline.

The general theorem is proved in research
`lem:odd-rank-scaled-unimodular-line-transitivity` at
[e2700d15](https://github.com/dzackgarza/research/commit/e2700d15bad77abf264f40a84c1853e7df003508),
using Peters--Sterk, Theorem 2.3.1. In odd rank, the positive Gram content
d and determinant identity |det L| = d^rank establish the untwisted
unimodular hypothesis. Both signature indices must be at least two.
A primitive null vector is noncharacteristic, splits a unimodular
hyperbolic plane, and the complementary odd indefinite unimodular
lattice is classified by its signature. This gives one ambient line
orbit, not a claim about the stable-kernel orbits. Other forms retain the
existing classifier.

The native Sage test uses the actual detached source path
`/repos/sage-extensions/.scratch/om319-0912/src`, verified before the
baseline. Both ambient regressions passed after the theorem-based
branch (Coble call 1.07 s, diagonal rank-five call 0.71 s; 2 passed in
13.27 s, test time gates disabled for diagnosis). This establishes the
ambient step only. The finite stabilizer image and full stable-kernel
consumer must still be checked, not inferred from ambient transitivity.
